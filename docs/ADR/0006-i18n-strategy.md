# ADR-0006: საიტის თარგმნა

## Status
მიღებული

## Context
FE-008: საიტი ორ ენაზე უნდა იყოს — ქართული (ნაგულისხმევი) და ინგლისური. API ორენოვანი არ არის: კატეგორიას აქვს `name` და `nameEn`, ფილტრების `label` მხოლოდ ქართულია (`key` და `value` — ინგლისური), აღწერა და `specs` მხოლოდ ქართულად მოდის, 422-ის შეცდომები — სერვერის ენაზე.

## Decision
- ბიბლიოთეკა — react-i18next: მრავლობითი რიცხვი (`_one` / `_other`), ჩანაცვლებები (`{{count}}`), `<Trans>` ტეგიანი ტექსტისთვის.
- ენა ინახება localStorage-ში, `<html lang>` ენის შეცვლისას განახლდება. გადამრთველი ჰედერშია და ავტორიზაციის გვერდებზეც.
- UI სრულად ითარგმნება — ტექსტები `src/locales/ka.json` და `en.json`-შია, ერთნაირი გასაღებებით.
- კატეგორია — `nameEn`; ფილტრები — ინგლისური სახელები `key`/`value`-ით (`filterLabels.js`), უცნობზე `value` ფორმატირდება.
- ვალიდაციის შეცდომები სქემებში გასაღებებია, `FormField` თარგმნის.
- ფასები და თარიღები — `Intl`, ერთი ჰელპერით (`formatPrice`, `formatDate`).
- `specs`, აღწერა და 422-ის შეცდომები ქართულად / სერვერის ენაზე რჩება.

## Consequences
- ენა F5-ს გადარჩება, იცვლება გვერდის გადატვირთვის გარეშე.
- ახალი ენა = ახალი JSON ფაილი + `LANGUAGES`-ში ერთი ჩანაწერი.
- ინგლისურ ვერსიაში მახასიათებლები და აღწერა ქართულად ჩანს — ცნობილი შეზღუდვაა.
- ბმული ენას არ ატარებს: გაზიარებული გვერდი მიმღების ენაზე იხსნება. URL-პრეფიქსი (`/en/catalog`) ამას გადაჭრიდა, მაგრამ ყველა მარშრუტს შეცვლიდა — ორი ენისთვის ზედმეტია.
- სწორი გადაწყვეტა: API-მ `Accept-Language` ჰედერი უნდა მიიღოს და ყველაფერი მოთხოვნილ ენაზე დააბრუნოს — ფრონტს მხოლოდ ჰედერის გაგზავნა დასჭირდებოდა.
- ზოგ ბრაუზერს (მაგ. Chrome) `ka-GE` ფორმატი არ აქვს — ამ შემთხვევაში იტვირთება FormatJS-ის Intl polyfill ქართული მონაცემებით (`src/i18n/polyfills.js`). ბრაუზერი, რომელსაც ქართული აქვს, ზედმეტ კოდს არ ტვირთავს.
- polyfill-ის ფაილები იტვირთება მხოლოდ ბრაუზერში, რომელსაც ქართული ფორმატი არ აქვს. FE-010-ში თარიღის polyfill (დროის სარტყლებით, ≈186 kB) ამოღებულია — ქართული თარიღი `formatDate`-ში 12 თვის სახელით იწერება; დანარჩენი polyfill-ები პარალელურად იტვირთება (ADR-0007, `docs/performance.md`).
