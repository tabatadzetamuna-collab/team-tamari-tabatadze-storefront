# ADR-0003: სად ვითხოვთ მიმდინარე პაროლს

## Status
მიღებული

## Context
FE-004: პროფილის ნებისმიერი ცვლილებისთვის (სახელი, ელფოსტა, პაროლი) სერვერი მიმდინარე პაროლს ითხოვს. ველი შეიძლება იყოს ფორმის ბოლოს ან დადასტურების მოდალში.

## Decision
მიმდინარე პაროლის ველი ფორმის ბოლოსაა, „შენახვის" ღილაკის ზემოთ.

## Consequences
- მარტივია: მოდალი, ფოკუსის მართვა და Esc არ გვჭირდება — ნაკლები კოდი და შეცდომის ალბათობა.
- 400 INVALID_CURRENT_PASSWORD პირდაპირ ამ ველზე ჩანს, ფორმა ღია რჩება.
- ფორმა ერთი ველით გრძელია; მომხმარებელი პაროლს ყოველ ჯერზე წერს.
