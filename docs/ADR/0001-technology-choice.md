# ADR-0001: ტექნოლოგიების არჩევანი

## Status
მიღებული

## Context
FE-001 ითხოვს სამ ავტორიზაციის ეკრანს კლიენტის ვალიდაციით და მრავალჯერად კომპონენტებს, API-ს გარეშე. ტექნოლოგიები დეველოპერის არჩევანია. ვმუშაობ მარტო, ვადა 5 კვირა.

## Decision
React + Vite, JavaScript, React Router, React Hook Form + Zod. სტილი — თითო კომპონენტს ცალკე CSS ფაილი, ფერები და ზომები CSS ცვლადებიდან (tokens.css). ინტერფეისი ქართულად.

JavaScript ავირჩიე TypeScript-ის ნაცვლად, რადგან TypeScript ჯერ კარგად არ ვიცი და ფოკუსი ფუნქციონალზე მინდა.

## Consequences
- ტიპების შემოწმება build-ისას არ ხდება — არასწორი props ან API-ის პასუხის ველი მხოლოდ გაშვებისას გამოჩნდება.
- ფორმის მონაცემებს Zod ამოწმებს; სქემები ერთ ფაილშია (validation.js).
- API-ის მოთხოვნები ერთ ფაილში იქნება (FE-002), ცვლილება ერთ ადგილას მოხდება.
- ატვირთვამდე ვუშვებ npm run lint-ს.
