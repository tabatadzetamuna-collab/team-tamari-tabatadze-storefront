ADR-0001: ტექნოლოგიები

პროექტისთვის ავირჩიე React და Vite. 
TypeScript-ის ნაცვლად ვწერ JavaScript-ზე, ეს უფრო მიადვილდება.
გვერდებს შორის გადასვლისთვის ვიყენებ React Router-ს, ფორმებისა და ვალიდაციისთვის კი React Hook Form-ს და Zod-ს.
ყველა კომპონენტს თავისი CSS ფაილი აქვს, ფერები და ზომები tokens.css-შია. საიტი ქართულ ენაზეა.
ფორმებს Zod-ით ვამოწმებ და ატვირთვამდე ვუშვებ npm run lint-ს.
