# ADR-0002: სად ვინახავ ტოკენს

## Status
მიღებული

## Context
შესვლისას სერვერი ტოკენს აბრუნებს (30 წუთი). F5-ის შემდეგ მომხმარებელი შესული უნდა დარჩეს.

## Decision
ტოკენს ვინახავ localStorage-ში, ყველაფერი tokenStorage.js-შია. საიტის გახსნისას GET /auth/me ამოწმებს, ტოკენი ისევ მოქმედებს თუ არა. აღდგენის ტოკენი მხოლოდ გვერდზე ინახება.
httpOnly cookie უფრო უსაფრთხოა, მაგრამ ეს API ტოკენს ჰედერით იღებს.

## Consequences
- რისკი: XSS-ით ტოკენის წაკითხვა შეიძლება. ამიტომ არ ვიყენებ dangerouslySetInnerHTML-ს და სხვა საიტების სკრიპტებს.
- ვადაგასულ ტოკენს httpClient.js ერთ ადგილას ამუშავებს და მომხმარებელი შესვლის გვერდზე გადადის.
