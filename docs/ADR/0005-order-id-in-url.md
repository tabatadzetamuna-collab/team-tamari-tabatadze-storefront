# ADR-0005: სად ინახება orderId კოდის ეკრანზე

## Status
მიღებული

## Context
FE-006: გადახდა ორი ნაბიჯია — შეკვეთის შექმნა (POST /orders → orderId) და კოდის დადასტურება (POST /orders/:id/confirm). კოდის ეკრანმა orderId უნდა იცოდეს. თუ მომხმარებელი ამ ეკრანზე F5-ს დააჭერს, orderId არ უნდა დაიკარგოს.

## Decision
orderId URL-შია: /checkout/confirm/:orderId. გვერდი მას useParams()-ით კითხულობს.

## Consequences
- F5-ზე, „უკან"/„წინ"-ზე და ბმულის ხელახლა გახსნისას orderId ადგილზეა.
- localStorage ან გლობალური მდგომარეობა არ გვჭირდება — არაფერი გასასუფთავებელი.
- orderId URL-ში ჩანს, მაგრამ ეს უსაფრთხოა: სერვერი სხვის შეკვეთაზე 404-ს აბრუნებს, და ბარათის მონაცემები URL-ში არ ხვდება.
